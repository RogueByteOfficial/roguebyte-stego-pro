# دليل واجهة سطر الأوامر (CLI) — RogueByte Stego Pro

**المطور**: SidoDev-Dz | **المؤسسة**: RogueByte

## الأوامر المدعومة

```bash
rb-stego <command> [options]
```

### 1. أمر التضمين (`embed`)
تضمين ملف أو مجموعة ملفات داخل صورة غطاء:
```bash
rb-stego embed --cover cover.png --input payload.zip --output result.png --encrypt
```
- `--cover <path>`: مسار صورة الغطاء (PNG, BMP, JPEG).
- `--input <path>`: مسار الملف المراد إخفاؤه (يمكن تكراره لتضمين عدة ملفات).
- `--output <path>`: مسار الصورة الناتجة.
- `--encrypt`: تفعيل التشفير بالمصادقة (AES-256-GCM).
- `--password <pwd>`: كلمة المرور (يطلبها البرنامج بأمان إن لم تُحدد).
- `--force`: الكتابة فوق الملف المخرج إن وجد مسبقاً.

### 2. أمر الاستخراج (`extract`)
استخراج الحمولات المخفية من صورة ستيغانوغرافية:
```bash
rb-stego extract --input result.png --output-dir recovered/
```
- `--input <path>`: صورة الستيغانوغرافيا.
- `--output-dir <dir>`: المجلد المستهدف لاستخراج الملفات (محمي بالكامل ضد ثغرات تخطي المسارات).
- `--password <pwd>`: كلمة المرور لفك التشفير.

### 3. أمر الفحص الجنائي (`inspect`)
تحليل رقمي جنائي شامل للصورة:
```bash
rb-stego inspect --input result.png
```
- يظهر قياسات الصورة، والسعة المتاحة، وإنتروبيا كل مستوى بت، وفحص كاي-تربيع، واكتشاف ترويسة RogueByte، ومستوى الثقة الجنائية.
- يدعم خيار `--json` للإخراج البرمجي.

### 4. أمر التحقق (`verify`)
حساب بصمة SHA-256 والتحقق من صحتها:
```bash
rb-stego verify --input recovered/payload.zip --expected <sha256>
```

### 5. أمر قياس السعة (`capacity`)
حساب أقصى سعة ممكنة للصورة:
```bash
rb-stego capacity --cover cover.png
```

---

## رموز الخروج (Exit Codes)

- `0`: نجاح العملية.
- `1`: خطأ عام.
- `2`: وسائط إدخال غير صالحة.
- `3`: خطأ في صورة الغطاء.
- `4`: خطأ في ملف الحمولة.
- `5`: سعة الغطاء غير كافية للحمولة.
- `6`: فشل المصادقة / فك التشفير (كلمة مرور خاطئة أو بيانات متلاعب بها).
- `7`: فشل التحقق من بصمة التكامل SHA-256.
- `8`: انتهاك أمني (محاولة تخطي المسارات Path Traversal).
